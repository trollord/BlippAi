# Luxury-lit V2 alternate

## Goal
Create a separate alternate page that preserves V2 exactly in content, typography, structure, and functionality while giving the dark canvas more intentional depth.

## Changes
- Keep `/v2` untouched and add the new treatment at `/v3`.
- Introduce subtle full-width tonal shifts between sections rather than boxes or cards.
- Add softly blended radial illumination behind key statements and selected sections, using the existing mint signal color plus restrained neutral light.
- Refine section dividers with low-contrast layered rules so transitions feel precise and luxurious.
- Keep backgrounds quiet enough that text remains the focus; no visible grid pattern, decorative imagery, or added interface elements.
- Preserve the contact form, navigation, responsive layout, and gentle reveals.

## Validation
